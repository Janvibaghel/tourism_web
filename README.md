🌄 Chhattisgarh Tourism Web

This project is a static website built to showcase the beautiful and lesser-known tourist destinations across Chhattisgarh, India. Each HTML page provides information on temples, waterfalls, caves, nature spots, and cultural heritage unique to various districts of the state.

🧭 Project Overview

The goal of this project is to promote tourism in Chhattisgarh by creating a district-wise web directory of attractions. Each file in the project corresponds to a specific district or category like nature, temples, or waterfalls.

Whether you're a tourist, student, or local explorer, this site serves as a simple and informative travel guide.

📁 Project Structure

Each HTML file follows a naming pattern that combines the district name and the category of attraction. For example:

BalodMain copy.html – Main attractions of Balod
BalodTemple copy.html – Temples in Balod
BastarWaterfall copy.html – Waterfalls in Bastar
GariyabandTemple copy.html – Temples in Gariyaband
...and many more, covering several districts and categories.

🚀 How to Use

To view the site locally:

Clone the Repository
git clone https://github.com/Janvibaghel/tourism_web.git
Navigate to the Folder
cd tourism_web
Open any HTML file in a browser You can start by opening BalodMain copy.html or any other page of interest.
No server setup required – this is a static HTML site.
